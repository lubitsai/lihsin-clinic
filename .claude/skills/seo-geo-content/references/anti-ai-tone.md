# 去 AI 味自檢清單（38 項）

適用：模式 B 新頁生產、既有文章改寫、最新消息、首頁卡標題——凡產出**可見文字**都適用。
模式 A 四層補強是零可見文字變更，只需查 §工具痕跡 兩項。

用法：落筆前掃 §0 豁免與六項 ⚠️；收尾交付前全表掃一次。

## §0 先讀：SOP 要求的東西不算 AI 味

本站 SOP 有幾項硬性要件會被下面的清單誤判。**這些一律保留，不得為了「去 AI 味」刪掉**：

| SOP 要件 | 會被誤判成 | 判定 |
|---|---|---|
| FAQPage ≥6 題、⚡快速重點速覽 | 編號切碎段落（26） | 保留。AEO/GEO 的結構需求，不是排版偷懶 |
| 疫苗四但書、「不單以數值忌口」 | 過度限定（33） | 保留。合規紅線（00 §4），刪掉即違規 |
| 危險徵象紅框條列、就醫時機段 | 內聯粗體標題列表（25） | 保留。安全資訊要能被掃讀 |
| 權威來源外連＋byline 參考來源 | ——（正是 8、5 的解方） | 保留並加強 |
| 「本院非急診」定位段 | 過度限定（33） | 保留。合規要求 |

判準一句話：**為了合規或讓家長找得到救命資訊而寫的，留；為了讓文章看起來完整而寫的，刪。**

## 內容類（9）

1. **誇大意義與趨勢**——「劃時代」「近年來越來越多家長」而無數據 → 刪，或換成可查證來源（疾管署統計、仿單）。
2. **過度強調關注度與媒體報導**——「引發各界熱議」「媒體廣泛報導」→ 衛教文一律刪。
3. **空洞分析收尾**——「總的來說，兒童健康需要家庭與社會共同關注」→ 收尾改成家長的下一步：何時該來、怎麼預約。
4. **廣告宣傳語氣**——與合規紅線重疊。可見區禁 推薦／最佳／第一／首選／權威／資深；promotional 詞只進 keywords meta 與 llms 層。
5. **模糊歸屬**——「有專家指出」→ 指名機構並掛外連（疾管署／國健署／台灣兒科醫學會），指不出來就刪整句。
6. **公式化前景段**——「挑戰與機遇並存」「展望未來」→ 衛教文不需要，刪。
7. **均值回歸**——通篇只有「保持良好衛生習慣」這種放諸四海皆準的話 → 換成本題專屬的具體動作（例：腸病毒要用肥皂搓洗，酒精乾洗手殺不掉）。
8. **幻覺引用**——引用與 sameAs 一律先 web_search 核對條目真的存在；查不到就不寫。誤連比不連更糟。
9. **立場真空**——該給建議時只寫「有人認為…也有人認為…」→ 醫師掛名文要給明確判準：什麼情況立刻就醫、什麼情況可先觀察多久。

## 語言與句式類（12）

10. **系詞迴避**——「腸病毒可說是一類具有…特性的病原」→ 直接寫「腸病毒是」。
11. **排比三段式**——「不只是 X，更是 Y，也是 Z」，或連續三段同構 → 拆開，長短句交錯。
12. ⚠️ **否定平行結構**——「不是 A，而是 B」→ 直接寫 B。這是最容易漏掉的一項，全文搜「不是」「並非」逐句看。
13. **刻意換詞循環**——同一個東西輪流叫「疫苗／該疫苗／此項預防措施」→ 就叫同一個名字。醫療文重複用詞是優點。
14. **虛假範圍**——「從發燒到心理健康」兩端不同層級 → 只留真的同層級的並列。
15. **解說導引句**——「值得注意的是」「事實上」「更重要的是」「換句話說」→ 刪掉，句子照樣成立。
16. ⚠️ **勸誡反問收尾**——「您準備好了嗎？」「何不從今天開始？」→ 換成事實型 CTA（門診時間、電話、LINE）。
17. **說教式深度腔**——「這背後反映的是…的深層問題」→ 刪。
18. ⚠️ **金句／格言公式**——「預防勝於治療，守護勝於補救」這類對仗句 → 刪。
19. ⚠️ **假坦白鉤子開場**——「說實話，多數家長都搞錯了一件事」→ 刪。第一句直接給答案，AEO 的答案前置本來就要求這樣。
20. **人工戲劇**——「令人震驚的是」「後果不堪設想」→ 危險徵象用事實描述即可（發燒超過幾天、活動力如何下降）。
21. **公式化開場**——「在少子化的今天」「隨著醫療進步」→ 刪，第一句就進主題。

## 風格與版面類（8）

22. **半形標點混用**——本專案不處理（排版慣例，各家規範不同）。
23. **破折號過度**——一段最多一個；中文改用逗號或括號多半更順。
24. **粗體過度**——一段最多一處粗體。整段粗體等於沒有重點。
25. **內聯粗體標題列表**——「**症狀：**發燒、喉嚨痛」整頁都是 → 能寫成句子的寫句子（安全資訊例外，見 §0）。
26. ⚠️ **編號切碎段落**——把本該連貫的說明切成 1./2./3. → 只在真並列時用（就醫時機、接種但書、FAQ）。
27. ⚠️ **表情符號堆疊**——內文零 emoji。站內既定 UI 標記（如速覽區的 ⚡）不算，沿用即可。
28. **表格誤用**——兩三個項目排成表格 → 三欄以上且真的要橫向比較才做表。
29. **句長過勻**——連續五句都在 25–35 字 → 刻意插一句短句。

## 溝通殘留類（7）

30. **協作交流殘留**——「希望這對你有幫助」「以上內容供參考」「如有其他問題歡迎提出」→ 刪。
31. **諂媚語氣與罐頭同理心**——「這是個很好的問題」「我完全理解您的擔憂」→ 刪。
32. **通用積極結論**——「相信在大家的共同努力下…」→ 刪。
33. **過度限定**——「可能」「或許」「在某些情況下」層層堆疊 → 一句最多留一個。合規但書不在此列（見 §0）。
34. **知識截止免責聲明**——「截至我的知識截止日」→ 一律刪。時效資訊改寫成「依 20XX 年 X 月疾管署公告」。
35. **模板佔位文字未填**——push 前全站搜 `[醫師`、`XXX`、`TODO`、`Lorem`。
36. **預告式導言**——「本文將分為三個部分說明」→ 刪，直接開始。

## 工具痕跡類（2）

37. **AI 工具殘留物**——外連貼上前清掉 `utm_source=chatgpt.com`、`oai_citation`、零寬字元 `&#8203;`。
38. **Markdown 標記錯置**——本站是純 HTML，內文出現 `**粗體**`、`##`、`- ` 列點即為錯，改成對應 HTML 標籤。

## 收尾快篩

交付前跑一次字串搜尋，命中即逐句判讀：

```
值得注意的是|事實上|更重要的是|換句話說|不是.*而是|並非.*而是
總的來說|綜上所述|希望.*有幫助|供參考|讓我們|您準備好
截至我的知識|utm_source=chatgpt|oai_citation
```

外加人工看兩件機器抓不到的事：**收尾段有沒有回到家長的下一步**、**有沒有哪一段刪掉之後全文不受影響**（有就刪）。
