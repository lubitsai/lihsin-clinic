#
# ⚠️ 這個檔 Netlify 不讀（只讀 `_headers`），放在這裡純粹是讓草案進版控。
#    要上線＝把下面「正式版」那段貼進 `_headers` 的 `/*` 區塊。

# ⚠️ 上線程序（internal/00 §6 既有裁示，勿跳過）：
#    ① 先以 Report-Only 版跑 Netlify Deploy Preview
#    ② 開 DevTools Console 逐頁看有沒有 CSP 違規回報
#    ③ 確認零違規後才換成正式版並 merge
#    直接上正式版會有「靜默擋掉 GA/Clarity/字型」的風險。
#
# ── 來源依據（2026-07-28 程式化盤點，非憑印象）──
# 掃全站 60 個 HTML＋根目錄 js，依標籤類型分別抓外部主機：
#   script src=       → www.googletagmanager.com
#   js 動態 .src=     → www.clarity.ms、www.googletagmanager.com（Chatbase 已於 2026-09-24 移除，改自建 /clinic-assistant/）
#   link href=(css)   → fonts.googleapis.com
#   字型實際下載      → fonts.gstatic.com
#   iframe src=       → maps.google.com（首頁地圖，1 處）
#   img src=          → 僅自家網域
#   fetch/XHR         → 無
# 其餘外部網域（cdc.gov.tw、hpa.gov.tw、pediatr.org.tw、wikipedia、
# line.me、mainpi.com、facebook、instagram、g.page、booknow…）**全是
# <a href> 超連結**，CSP 不管轄，無須列入。
#
# ── 各來源對應的指令 ──
#   Google Fonts   → style-src（CSS）＋ font-src（字型檔）
#   GA4 gtag       → script-src（googletagmanager）＋ connect-src（google-analytics）
#   Microsoft Clarity → script-src（www.clarity.ms 載 tag）
#                     ＋ connect-src（*.clarity.ms 回傳錄影／c.bing.com）
#   線上小幫手     → 'self' 即可（/clinic-assistant/ 同網域 module＋JSON；Shadow DOM 內 <style> 受 style-src 'unsafe-inline' 涵蓋）
#   Google Maps    → frame-src（首頁 iframe）
#
# ── 2026-11-26c 重盤補上的三處（07-28 版沒有，照舊版上正式會壞）──
#   frame-src  + https://www.youtube-nocookie.com  → 學員專區 /members/nutrition/ 影片
#   media-src  'self' blob:   → 學員專區音檔解密後以 blob: 播放（舊版無此指令＝落回 default-src，Playwright 實測會被擋）
#   img-src    + blob:        → 學員專區結業紀念卡 canvas→blob 圖（同上實測會被擋）
#   另依 Google／Microsoft 公開 CSP 建議放寬：GA4 改 *.googletagmanager.com、img-src 補 GA4 與 Clarity 信標主機。
#   本機 Playwright 以 Report-Only 爬 147 頁：違規 0（唯一回報為 logo 絕對網址在 localhost 測試源下的假陽性，正式站屬 'self'）。
#   容器代理擋 googletagmanager／clarity，GA／Clarity 實際送出**未在容器驗證**，須在 Deploy Preview 人工確認（下方驗收點 2、3）。
#
# ⚠️ 'unsafe-inline' 兩處都拿不掉的原因：
#   script-src：各頁的 JSON-LD（<script type="application/ld+json">）**受
#     script-src 管轄**，加上 gtag config 與頁內 inline script，靜態多頁站
#     沒有 nonce 機制 → 只能保留，或改走 hash（60 頁維護成本過高）。
#   style-src：各頁有 inline style 屬性與頁內 <style> 區塊。
#   → 這是靜態站的已知取捨；CSP 在此的價值主要在 object-src/base-uri/
#     form-action/frame-ancestors 與限制外連白名單，不是擋 XSS 的全部。
