#
# ── 來源依據（2026-07-28 程式化盤點，非憑印象）──
# 掃全站 60 個 HTML＋根目錄 js，依標籤類型分別抓外部主機：
#   script src=       → www.googletagmanager.com
#   js 動態 .src=     → www.chatbase.co、www.clarity.ms、www.googletagmanager.com
#   link href=(css)   → fonts.googleapis.com
#   字型實際下載      → fonts.gstatic.com
#   iframe src=       → maps.google.com（首頁地圖，1 處）
#   img src=          → 僅自家網域
#   fetch/XHR         → 無
# 其餘外部網域（cdc.gov.tw、hpa.gov.tw、pediatr.org.tw、wikipedia、
# line.me、mainpi.com、facebook、instagram、g.page、booknow…）**全是
# <a href> 超連結**，CSP 不管轄，無須列入。
#
# ── 各來源對應的指令 ──
#   Google Fonts   → style-src（CSS）＋ font-src（字型檔）
#   GA4 gtag       → script-src（googletagmanager）＋ connect-src（google-analytics）
#   Microsoft Clarity → script-src（www.clarity.ms 載 tag）
#                     ＋ connect-src（*.clarity.ms 回傳錄影／c.bing.com）
#   Chatbase       → script-src ＋ connect-src ＋ frame-src（widget 內嵌）
#   Google Maps    → frame-src（首頁 iframe）
#
# ⚠️ 'unsafe-inline' 兩處都拿不掉的原因：
#   script-src：各頁的 JSON-LD（<script type="application/ld+json">）**受
#     script-src 管轄**，加上 gtag config 與頁內 inline script，靜態多頁站
#     沒有 nonce 機制 → 只能保留，或改走 hash（60 頁維護成本過高）。
#   style-src：各頁有 inline style 屬性與頁內 <style> 區塊。
#   → 這是靜態站的已知取捨；CSP 在此的價值主要在 object-src/base-uri/
#     form-action/frame-ancestors 與限制外連白名單，不是擋 XSS 的全部。
