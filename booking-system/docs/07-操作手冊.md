# 07｜櫃檯與管理員操作手冊

後台網址：`https://booking.lhpedclinic.com.tw/admin`
閒置 30 分鐘自動登出（可於系統設定調整）；所有操作都有稽核紀錄。

## 一、每日流程（櫃檯）

1. **登入** → 首頁即為「今日預約總覽」：左欄時間、蔡醫師／李醫師各一欄（手機顯示卡片）。
2. 上方卡片顯示每位醫師「已預約／總名額／剩餘」。
3. 病人到診 → 點該筆的 **報到**；看診結束 → **完成**。
4. **紅框＋「報到逾時」**＝已過該時段的報到保留時間（預設 10 分鐘）仍未報到。
   這只是提醒，系統**不會**自動取消，請依現場狀況處理：
   - 人其實已經在等 → 照常點 **報到**。
   - 人到了但已逾時、重抽現場號看診 → 依院長規則**不算未到**，請點 **報到**（或看完點 **完成**），
     不要點未到。
   - 當天都沒出現 → 點 **未到**（會累計未到次數；累計達 3 次自動暫停網路預約 3 個月）。
5. 誤按未到 → 「撤銷未到」可還原並扣回次數。
6. 電話取消 → **取消**（輸入原因，系統自動通知病人）。
7. 要改時間 → **改期**（進入改期頁選新時段，原單自動標「已改期」）。
8. 日結：右上 **列印** 或 **匯出 CSV**（匯出檔證件號一律遮罩）。

> **開診後家長打電話來要取消或改期怎麼辦？**
> 該診次開診後民眾就不能自己在系統上取消（官網公告如此），但**櫃檯不受這個限制**，
> 可直接在總覽上操作。

### 常用篩選

上一天／今天／下一天、日期選擇器、早午晚診、醫師、門診類型、狀態，
搜尋框支援：姓名、電話、證件末碼、預約編號。

### 「待確認」狀態

**目前四種門診都是送出即成立**（院長 2026-08-05 裁示），正常情況不會出現「待確認」。
若日後在「系統設定 → 門診類型」把某科改回「需櫃檯審核」，該科新單會是待確認（黃色⏳），
確認後點 **確認**，病人會收到通知。

## 二、代客預約

「代客預約」頁 → 搜尋既有病人或建新病人 → 選門診/日期/時段（櫃檯可見全部時段）→ 建立。
若撞到「同日已有預約」「同時 2 筆未完成預約」「預約限制」，系統會要求輸入**覆寫理由**才能強制建立（留稽核）。

## 三、排班調整

> **常態班表以官網門診時間表為準，不要在後台直接改週班表。**
> 官網改了之後由維護官網的人跑同步（`sync_schedule.py` ＋ 主機上的 `npx tsx scripts/sync-schedule.ts`），
> 系統會自動跟上；在後台手改週班表，下次同步就會被蓋掉。
> 後台要用的是**單日的例外**（臨時停診、代診、加開名額）——那些同步不會動。

「排班管理」三個分頁：

| 分頁 | 用途 |
|---|---|
| 固定週班表 | 每週固定班（星期×診別×醫師×時間×名額×是否開放線上） |
| 日期例外 | 全日休診／診別休診／醫師休診／代診／特殊時間／加診／封鎖時段／暫停門診類型 |
| 時段名額調整 | 單一時段手動加開名額（需原因） |

**重要**：例外若影響已存在的預約，系統會**先列出受影響病人**，不會刪除任何預約。
選擇：逐筆「改期」，或「批次診所取消＋通知」。兩者都會自動發 LINE／簡訊。

## 四、病人與未到管理

- 「病人管理」搜尋 → 病人頁可看：遮罩證件號、過去/未來預約、取消/未到次數、限制狀態、後台備註。
- 未到累計**超過 3 次**（第 4 次）系統自動限制其線上預約；前台只顯示「請致電診所」（不會出現「黑名單」字樣）。
- 解除／暫時解除（設到期日）／重設未到次數 → **僅管理員**，需輸入原因。
- 可能重複病歷（同名同生日等）列在病人管理頁下方，**僅管理員**可合併（輸入「合併」二字確認；原始資料保留）。
- 「顯示完整號碼」需管理員權限，且每次查看都寫入稽核。

## 四之二、放假日行事曆（每年更新一次）

**115（2026）年已內建，不需要做任何事。**
行政院人事行政總處每年約 6 月公布次年「政府行政機關辦公日曆表」，
屆時下載 CSV 後在主機執行一次即可：

```
npx tsx scripts/import-holidays.ts 日曆表.csv --source dgpa-116
npx tsx scripts/import-holidays.ts --list        # 查看已匯入範圍
```

匯入後，行事曆上的放假日當天**兒童發展篩檢自動不開放線上預約，一般門診照常**。
後台「系統設定 → 國定假日行事曆」可看涵蓋到哪一天；**快到期會出現警告**，看到就該匯入次年度。
哪些門診要在假日停開，可在「系統設定 → 門診類型」逐科勾選。

> 假日當天若連門診時間都有異動（例如提早收診），那是另一件事——走官網門診異動公告，
> 系統會隨官網班表同步（見第三節）。

## 五、管理員專屬

| 功能 | 位置 |
|---|---|
| 員工帳號建立/停用/重設密碼 | 員工帳號頁（櫃檯人員無法進入，也不能動任何帳號） |
| 兩步驟驗證（TOTP） | 員工帳號頁下方，掃 QR 後輸入 6 位數啟用 |
| 預約規則（開放天數/上限/未到門檻/截止時間） | 系統設定 |
| 門診類型（開放/審核/年齡/星期/診別/醫師/文案/顏色） | 系統設定 |
| 醫師新增/停用 | 系統設定（不限兩位） |
| 稽核紀錄查詢 | 稽核紀錄頁 |

## 六、醫師唯讀帳號

員工帳號頁建立角色「醫師唯讀」並對應醫師本人 → 該帳號登入只能看自己的當日預約，無任何操作按鈕。

## 七、常見問題

- **病人說收不到通知**：病人頁確認 LINE 綁定狀態；封鎖官方帳號會自動改發簡訊；可在總覽點「傳送通知」補發。
- **帳號被鎖**：連續 5 次密碼錯誤鎖 15 分鐘；急用時請管理員重設密碼。
- **誤標未到**：該筆點「撤銷未到」，次數自動回沖。
- **系統顯示「操作失敗」**：重新整理後再試；持續發生請聯絡維護人員並附上時間點（稽核紀錄可對照）。
