```
【疫苗接種：公費與自費，從新生兒到長輩】

立欣診所提供公費與自費疫苗接種，家中大小的疫苗可以在同一個地方安排。

公費疫苗依疾管署公告的國家接種時程提供，家長可對照兒童健康手冊（黃卡）安排，常見的有五合一、四合一、肺炎鏈球菌、水痘、MMR、A 型肝炎、日本腦炎，以及學齡 HPV 與每年流感（依公告對象與時程）。
```

### C1. 台南哪裡可以打疫苗（扛頭部詞）

**問**
```
請問你們有打疫苗嗎？公費自費都有嗎？
```

**答**
```
有的，公費與自費疫苗都可以接種，從新生兒、學齡兒童到成人長輩都有。公費依疾管署公告的國家接種時程，對照兒童健康手冊（黃卡）安排；自費常見的有輪狀病毒、腸病毒 71 型、Bexsero、15 價肺炎鏈球菌、RSV 樂唯初、HPV 嘉喜 9 價、帶狀皰疹欣剋疹、水痘與流感等，適用對象與劑數依原廠仿單與醫師評估。自費品項的現貨會變動，來之前建議先撥 06-2516086 或加 LINE @lhpedclinic 確認當日庫存。另提醒每日最後一診前 1 小時停止施打，要接種請提早到院。完整說明見官網 https://lhpedclinic.com.tw/services/vaccination.html 。本院為一般門診、非急診。
```

### C2. 可以同一天打多種疫苗嗎（站內外口徑一致）

> 這題 08-24c 批剛補上官網可見層，答案逐字對齊，**官網／GBP 兩處口徑相同**。
> 若日後 Chatbase 知識庫也要收，用同一份答案即可（三載體同步）。

**問**
```
小朋友可以同一天打兩種疫苗嗎？
```

**答**
```
多數不活化疫苗與部分疫苗可以在同次就診分開不同部位接種。實際能不能同時接種、或需要間隔多久，依各疫苗原廠仿單與醫師評估而定，例如活性減毒疫苗之間可能需要間隔。接種前請主動告知近期的接種紀錄與用藥史，由醫師依當日狀況與仿單安排。接種後請於院內觀察 15 到 30 分鐘。詳見官網 https://lhpedclinic.com.tw/services/vaccination.html 。
```

### C3. 流感疫苗（時效性較低的問法，9/16 之後只需微調一句）

**問**
```
流感疫苗什麼時候可以打？有分哪幾種？
```

**答**
```
公費流感疫苗依疾管署每年公告的時程與對象接種，通常秋季開打，6 個月以上嬰幼兒、孕婦、長者等為主要對象之一；不符公費資格者可接種自費流感疫苗。本院 2026 年提供 5 款自費廠牌，都是三價疫苗，其中東洋輔流禦含佐劑、仿單適用 50 歲以上，AZ 能伏鼻為鼻腔噴劑、減毒活性、仿單適用 2 歲到未滿 18 歲，鼻噴劑型由醫師親自執行接種。哪一款適合請由醫師依仿單與個人狀況評估。各款比較見官網 https://lhpedclinic.com.tw/news/flu-vaccine-2026.html 。現貨與費用請來電 06-2516086 或 LINE @lhpedclinic 確認。
```
