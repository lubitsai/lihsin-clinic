> **先讀這一段**：本目錄的 `README.md` 與 `checksums.sha256` 是**院長原始遊戲包的附件逐字副本**，不是站點檔、不對外（`_redirects` §5 `/internal/*` 已強制 404）。

## 2. 對原始包做過的唯一兩項改動（皆為技術層，可見文字一字未改）

| 檔案 | 改動 | 原因 |
|---|---|---|
| `game/game.html` | 移除檔末 **Cloudflare challenge 注入腳本**（`window.__CF$cv$params` ＋ `/cdn-cgi/challenge-platform/scripts/jsd/main.js`，938 bytes）＋ 新增 `<meta name="robots" content="noindex, follow">` | 原站掛在 Cloudflare 後方、存檔時被一併帶下來；該路徑在 Netlify 不存在，留著等於每次載入插一個隱藏 iframe 打 404（驗證器 E-LINK 抓到）。noindex 依院長「只給連結不進搜尋」裁示 |
| `game/index.html` | 新增 `<meta name="robots" content="noindex, follow">` | 同上裁示 |

**其餘 11 檔（9 張 3D 圖＋`manifest.webmanifest`＋`sw.js`）與原始包 byte-identical。**

## 3. 校驗現況（2026-08-16 實跑）

```
cd game && sha256sum -c ../internal/game/checksums.sha256
```

預期結果：**11 OK ／ 2 FAILED（`index.html`、`game.html`）／ 1 缺檔（`README.md`，已移來本目錄）**。
兩個 FAILED **就是 §2 那兩項改動造成的，屬正常**。

改動後的實際雜湊（2026-08-16 起的基準值）：

```
8ebd5720d3a2192dfb040ca35a0e87ed0473bab7622634f0d0d7bdbf19cef8e9  game/index.html
2f5480f6bdac20a29a9c8eae2329e7f3ea45ce6153518f1809204b63c4e91880  game/game.html
```

**判讀規則**：11 個 OK 的檔案若哪天變成 FAILED ＝ 有人動了不該動的資產；上面兩個雜湊若對不上 ＝ 有人改了遊戲頁（可能是拿原始包直接覆蓋，**要立刻確認 CF 腳本有沒有被帶回線上**）。

## 4. 動這個遊戲前必看（重複記載於 00 2026-08-16 版本區塊、01 現在狀態段）

1. **更新任何 `game/` 檔案時，必改 `game/sw.js` 的 `CACHE = 'lihsin-deer-doctor-sites-v9'` 尾碼 +1**——它是 cache-first，不改版號的話玩過的裝置會一直吃舊版。
2. **拿新版原始包覆蓋前，先 `grep -c cdn-cgi game.html`**，確認沒有把 Cloudflare 注入腳本帶回來；再跑 `validate_site.py` 看 E-LINK。
3. **遊戲可見文字受 §4 保護**，與官網頁面同一標準：要改先經院長核可。結算語「小鹿醫師最佳助手」已由院長 2026-08-16 逐字核可入 `VISIBLE_ALLOWLIST`，**僅限遊戲脈絡、不外溢**。
4. **驗證器對 `game/` 兩檔有 `pwa`／`h1`／`twcard` 三項 `EXEMPT` 豁免**；日後若改為「上架 SEO」（進 sitemap／官網放連結），三條豁免須同批撤除並補 canonical／H1／OG／twitter:card。
