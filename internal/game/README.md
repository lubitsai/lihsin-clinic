# 立欣診所｜小鹿醫師 3D 看診趣

此壓縮檔整理自目前公開網站的最新版本，包含完整六關遊戲、台灣中文語音設定、3D 圖像、網站圖示、安裝資訊與離線快取。

## 快速使用

1. 解壓縮全部檔案。
2. 直接開啟 `index.html` 即可遊玩。
3. 若要放到網站空間，請將整個資料夾內容一起上傳，並以 `index.html` 作為首頁。

## 主要內容

- `index.html`：可攜式網站首頁
- `game.html`：完整遊戲程式與介面
- `brand-3d.png`：立欣診所品牌圖像
- `mascot-3d.png`：小鹿醫師圖像
- `patient-3d.png`、`patient-mouth-3d.png`：虛擬病患圖像
- `tool-*.png`：聽診器、耳鏡、喉嚨與鼻子工具圖像
- `app-icon-3d.png`：網站與加入主畫面圖示
- `manifest.webmanifest`：網頁應用程式設定
- `sw.js`：離線快取程式
- `checksums.sha256`：檔案完整性校驗碼

## 注意事項

- 台灣中文配音會使用裝置內可用的 `zh-TW` 語音；不同手機或電腦的實際聲音可能略有差異。
- 瀏覽器通常需要先點擊「開始勇氣任務」，才會允許播放語音與音效。
- `sw.js` 的離線快取功能需透過 HTTPS 或本機網站伺服器使用；直接雙擊開啟仍可遊玩，但不會啟用離線快取。
