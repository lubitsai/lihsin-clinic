## 一、定位（一段話）

官網的角色是讓人確認可以信任，Reels 的角色是讓人第一次認識診所。家長在 FB／IG 滑到院長的衛教短片，之後再到官網、Google 商家檔案確認，最後用 LINE 預約。所以每支片和每則貼文只放**一個 CTA**，導到官網對應的衛教頁，或導到 LINE @lhpedclinic。受眾是台南北區、永康、東區一帶的家長。人設是會把話講清楚的過敏氣喘醫師，語氣溫和、不責備家長。

## 二、錄音到成片工作流（`internal/tools/make_short.sh`）

這套流程 2026-10-10 已經存進 repo，**院長錄一段口述，在自己的 Mac 上跑一條指令，就能做成 9:16 Reels**。本節說明怎麼把它用在本企劃。

### 2-1 分工

| 誰 | 在哪裡 | 做什麼 |
|---|---|---|
| 院長 | 手機＋自己的 Mac | 照第四節的提詞稿錄音 → 跑 `make_short.sh` → 校字幕 → 看成片 → 上片 |
| Claude session | 雲端 | 擬字卡標題與提詞稿（附備選）、校對院長貼回來的 `cut.srt`、做合規把關、依錯誤訊息除錯 |

雲端 session 沒有 Whisper／Auto-Editor，也拿不到院長的錄音，**成片只能在院長的 Mac 上產出**。影片、錄音、SRT 一律不進 repo。

### 2-2 每支片的五項輸入

```
internal/tools/make_short.sh <錄音> <背景圖> <配樂> "<字卡標題>" [片頭.mp4] [片尾.mp4]
```

| 輸入 | 本企劃的做法 | 每支都要換？ |
|---|---|---|
| 錄音 | 院長照第四節提詞稿口述，30～45 秒 | 換 |
| 背景圖 | 共用 2～3 張（見 2-4），依主題選一張 | 通常不用 |
| 配樂 | 共用 1～2 首有授權的輕音樂（見 2-4） | 不用 |
| 字卡標題 | 第四節每支的「字卡標題」，只在前 3 秒顯示 | 換 |
| 片頭／片尾 | 不用片頭（前 3 秒要給字卡）；片尾共用一支 5 秒的診所位置片（見 2-4） | 不用 |

### 2-3 院長端步驟（一支約 15 分鐘）

1. **錄音**：用手機內建錄音 App，在下班後安靜的診間錄。手機離嘴巴約一個手掌寬，一支片存成一個檔，例如 `reel01.m4a`。
   - 講錯了就**整支重錄**（30～45 秒很短）。工具只會刪掉停頓，**不會刪掉講錯的句子**，在字幕檔裡刪掉某一行也不會剪掉聲音。
   - 句子之間自然停頓就好，工具會自動把停頓縮短。
2. **跑指令**（第一次執行前先安裝：`brew install ffmpeg imagemagick`；`pip install openai-whisper auto-editor`）：
   ```bash
   OUT_DIR=reel01_out internal/tools/make_short.sh reel01.m4a bg_clinic.jpg bgm.mp3 "東北季風來了\n孩子夜咳變多？" "" outro_5s.mp4
   ```
   - 字卡標題要分兩行時，中間放 `\n`（已實測 ImageMagick 會換行）。每行最多約 **11 個字**（84pt 字、畫面寬 1080），太長會超出畫面。
   - 不用片頭時，第 5 個參數放空字串 `""`，片尾放第 6 個。
3. **校字幕**：腳本跑到一半會停下來，等你校對 `reel01_out/cut.srt`。可以自己改，也可以把整份 SRT 貼回 Claude session，請它照 short-video Skill 的清單校稿（簡體字、藥名、醫療用語、每條 ≤16 字）。
   - 字幕是院長口述的逐字稿，**只能改錯字**。如果講出口的內容踩到紅線，就整支重錄，不要只改字幕、讓字幕和聲音對不上。
4. 校完按 Enter，產出 `reel01_out/final_9x16.mp4`。
5. **在手機上完整看一遍**，檢查三件事：字卡有沒有被背景圖的文字蓋住、字幕有沒有擋到院長的臉、配樂會不會蓋過人聲（太大聲就設 `BGM_VOLUME=0.08` 重跑）。
6. **發布前檢核**：把字卡標題、SRT、貼文文案貼給 Claude session，跑「行銷工具組」的〈共用發布前檢核提示詞〉。通過後，由院長逐字核可。
7. **上片**：FB 和 IG 同步發 Reels，貼上第四節的貼文文案和第三節的固定尾註。

### 2-4 共用素材（一次備齊，之後每支重複用）

| 素材 | 規格 | 怎麼準備 |
|---|---|---|
| 背景圖 A｜院長白袍照 | 直式，至少 1080×1920；**上方約 1/4 留白**（字卡會疊在上方） | 診間拍一張院長半身照，不要有病患入鏡，背景乾淨 |
| 背景圖 B｜診間設備 | 同上 | 肺功能檢測儀或 InBody 270 的空機照，用在過敏氣喘、檢查類主題 |
| 背景圖 C｜小鹿醫師 | 同上 | 用正式小鹿 mascot 原檔做成奶油色底的直式圖，用在新生兒、疫苗類主題 |
| 配樂 | mp3，輕柔、沒有人聲 | 只用確定可以商用、可以放上 FB／IG 的授權音樂（〔待確認〕向音樂來源核對授權條款）。工具會把配樂直接混進影片，**之後在 IG 裡換不掉**，所以授權要先確認 |
| 片尾 `outro_5s.mp4` | 1080×1920、30fps、要有音軌 | 從已核可的宣傳片 `/videos/earth-to-clinic-9x16.mp4` 剪最後 5 秒（大頭針＋「立欣診所／臺南市北區育德路 467 號」資訊卡 → 店面），再加上靜音音軌，指令見下方 |

製作片尾的指令（在 repo 根目錄執行，2026-11-05 已在 session 實測：產出 1080×1920、30fps、有音軌，長度正確）：

```bash
ffmpeg -nostdin -y -sseof -5 -i videos/earth-to-clinic-9x16.mp4 \
  -f lavfi -i anullsrc=r=48000:cl=stereo -map 0:v -map 1:a -t 5 \
  -c:v libx264 -crf 20 -pix_fmt yuv420p -r 30 -c:a aac -b:a 192k outro_5s.mp4
```

⚠️ 宣傳片最後的店面畫面，拍到了**公費流感疫苗開打的布條**。流感季結束、布條撤下後，建議重拍店面、重做宣傳片，或把片尾改成只剪到資訊卡為止（`-sseof -5 -t 2`），避免片尾出現過期的疫苗公告。

### 2-5 這套工具做不到的事（直接說清楚）

- **整支片只有一張背景圖**，字卡也只在開頭出現一次。中段要換畫面、跳出紅底警訊卡、插入設備操作的影片，都要用剪輯軟體（例如 CapCut）另外後製。所以第四節的提詞稿都設計成**院長講一段話就能講完**，危險徵象這類重點，靠口述加上字幕呈現，貼文裡再完整列一次。
- **不能剪掉講錯的內容**，見 2-3 第 1 點。
- 想要「院長說話時配樂自動變小聲」，要改腳本（short-video Skill 有寫方法），改完一定要實際跑過驗證。

## 三、合規守則（每支片都適用）

以 `行銷工具組_30項_20261010.md`〈合規紅線〉8 條為準，以下只列出短影音特別容易踩到的地方：

1. **禁語**：字卡、字幕、貼文都不出現「推薦、最佳、第一、首選、權威、資深、頂尖、唯一、最專業」，也不寫「治好了」「根治」「保證」。院內設備、看診時間可以用事實陳述，例如「院內有肺功能檢測儀」「週六、週日都有門診」。
2. **不寫價格**：不寫任何價格數字、折扣，也不出現「優惠」字樣。被問到費用，一律回「請來電或 LINE 詢問」。
3. **疫苗四項但書缺一不可**（字幕或貼文至少有一處完整呈現）：①適用年齡、劑次依原廠仿單 ②接種前由醫師評估 ③現貨請先來電或 LINE 確認 ④每日最後一診結束前 1 小時停止施打（實際時間以官網就診指南為準，**不要寫死時刻**）。
4. **過敏檢測**：要附「不單以檢測數值決定忌口，由醫師綜合症狀判讀」。
5. **專科與急診**：不自稱過敏專科、耳鼻喉專科；慢性病寫「控制與追蹤」。講到就醫時機，一定要說「危急狀況請直接到急診或撥 119，本院是門診、不是急診」。
6. **師承**：可以客觀講在台北馬偕受過的訓練，不能暗示指導醫師在本院看診，或替本院背書。
7. **不寫評分**：不提 Google 星數或評論數字。
8. **不拍病患、不講個案、不用見證**：畫面只有院長、空機設備、小鹿圖。需要舉例時，明說是「假設情境」。
9. **開場不嚇人**：前 3 秒直接給答案或丟出家長真正會問的問題，不用「說實話，很多家長都搞錯了」這種假坦白，也不用「後果不堪設想」這種恐嚇（`anti-ai-tone` 第 19、20 項）。
10. **留言區不看診**：個人病情一律回覆「每個孩子狀況不同，建議到門診由醫師評估，可以用 LINE @lhpedclinic 預約」。不證實留言者是本院病患（`02` §3-4）。
11. **標籤只放 3～5 個**和主題相關的，不使用 #小鹿醫師團隊。

### 11 月四支：完整提詞稿（院長照著念，可以改成自己習慣的口語）

每支口白約 100～130 字（約 30～40 秒，實際長度以試讀為準）。〔待查核〕表示發布前要再查證來源。

#### ① 東北季風來了，孩子夜咳變多？

- **字卡**：東北季風來了\n孩子夜咳變多？（備選：天氣一冷\n孩子就咳不停？）
- **提詞稿**：
  > 天氣一變冷，門診常有家長問：孩子一到晚上就咳，是不是又感冒了？冷空氣和早晚溫差，本來就容易誘發氣喘孩子的呼吸道〔待查核：以台灣兒童過敏氣喘免疫及風濕病醫學會或 GINA 指引核對措辭〕。如果孩子常常半夜咳、清晨咳，或是一運動就咳、就喘，建議帶來門診評估，六歲以上可以做肺功能檢查。平常在用的控制藥，不要因為一時好轉就自己停掉。如果呼吸很喘、講話講不完整，請直接去急診。
- **貼文要點**：列出夜咳、清晨咳、運動後咳三個警訊；說明控制藥不要自行停用；附急診警語；連到過敏氣喘門診頁。
- **標籤**：#兒童氣喘 #夜咳 #台南小兒科 #台南兒童過敏
- **院長務必確認**：「六歲以上可以做肺功能檢查」與服務頁「本院安排 6 歲以上的孩子施測」一致。

#### ② RSV 季節，小寶寶怎麼保護？

- **字卡**：RSV 季節\n小寶寶怎麼保護？（備選：RSV 是什麼？\n新手爸媽看這裡）
- **提詞稿**：
  > RSV 是呼吸道融合病毒，是小寶寶下呼吸道感染、住院的常見原因，愈小的寶寶風險愈高。現在有長效單株抗體樂唯初，打一次大約可以保護五個月，涵蓋一個流行季。它是直接把抗體給寶寶，和一般疫苗的作用方式不一樣。適不適合打，依原廠仿單，由醫師看寶寶的年齡、出生季節和健康狀況評估。想打的話，請先來電或 LINE 確認現貨。
- **貼文要點**：疫苗四項但書要寫齊（停打時間寫「每日最後一診結束前 1 小時停止施打，實際時間請看官網就診指南」）；常見副作用是注射部位紅腫、輕微發燒；不寫價格；連到 RSV 衛教頁。
- **標籤**：#RSV #樂唯初 #新手爸媽 #台南小兒科
- **院長務必確認**：RSV 衛教頁由**李佳玲醫師審閱**，請決定這支由院長錄，還是請李醫師錄。

#### ③ 氣喘吸類固醇，會長不高嗎？

- **字卡**：氣喘吸類固醇\n會長不高嗎？（備選：吸入型類固醇\n可以放心用嗎？）
- **提詞稿**：
  > 很多家長一聽到類固醇就擔心，孩子會不會長不高？吸入型類固醇是直接噴到呼吸道，劑量比口服的低很多，兩者是不同的東西〔待查核：成長影響的措辭，以醫學會或仿單核對，不寫具體公分數〕。氣喘控制不好，孩子晚上睡不好、不敢運動，對生活的影響其實更大。要不要用藥、什麼時候可以減量，請和醫師討論，不要自己停藥。
- **貼文要點**：重申「請勿自行停藥或長期自行使用，用藥與減量由醫師評估」（child-wheezing 頁的原有措辭）；連到喘鳴衛教頁或過敏氣喘門診頁。
- **標籤**：#兒童氣喘 #吸入型類固醇 #台南小兒科 #台南兒童過敏

#### ④ 流感疫苗還沒打？看這裡
