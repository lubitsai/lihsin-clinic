```
【開學季：流感、腸病毒、新冠一起流行，症狀怎麼分】

開學後孩子回到教室、共用空間與物品，這三種病毒的傳染途徑重疊，同一個班級可能同時有不同病毒在傳。三者都會發燒、症狀也有重疊，家長最實用的是這三個線索：

・嘴破，加上手掌、腳掌、臀部的水泡或紅疹，偏向腸病毒
・突然發作的高燒，合併明顯頭痛、肌肉痠痛與極度疲倦，偏向流感
・喉嚨痛為主，而且班上或家中有明確接觸史，偏向新冠

這些是機率上的差別。單看症狀無法確診，仍需醫師結合症狀、病程與接觸史評估，必要時安排檢驗；快篩陰性也不能完全排除感染。

什麼時候要立刻送醫：呼吸急促或呼吸困難、嘴唇或臉色發紫發青、意識改變或叫不太醒、抽搐、持續嘔吐，以及 3 個月以下嬰兒發燒不論幾度。腸病毒另要留意重症四大前兆——嗜睡與活動力明顯變差、肌躍型抽搐、持續嘔吐、呼吸急促或心跳加快。出現任一項請直接前往急診或撥 119，不要為了先做檢驗而延誤。

孩子還在發燒、活動力與食慾明顯變差時，先在家休息。腸病毒發病後一週內傳染力最強，建議自發病日起至少請假隔離 7 天；停課標準各縣市不同並會隨疫情調整，請洽學校或當地衛生局。也提醒一件常被誤解的事：酒精與乾洗手液對腸病毒幾乎無效，流行期請用肥皂勤洗手，環境消毒用稀釋的含氯漂白水。

門診時間：平日上午 08:00–12:00、下午 14:30–18:00、夜間 18:30–21:30；週六上午 08:00–11:30、下午 14:30–18:00；週日上午 08:00–11:30、夜間 18:30–21:00。開學季孩子晚上或假日不舒服，不必等到平日。

本院為一般門診、非急診；急重症請撥 119 或前往鄰近急診。
```

### C1. 三者怎麼分（扛「開學季」與「怎麼分」整條詞路）

**問**
```
開學後小孩發燒，怎麼知道是流感、腸病毒還是新冠？
```

**答**
```
三種都會發燒、症狀也重疊，但各自有比較有指向性的表現。腸病毒的指標是嘴破（口腔潰瘍），常合併手掌、腳掌、臀部的小水泡或紅疹，孩子會因為喉嚨痛而不肯吃東西、流口水。流感常突然發作，以高燒、明顯頭痛、肌肉痠痛與極度疲倦為主，家長常形容成「本來還在玩，突然燒起來整個人癱掉」。新冠則常見喉嚨痛、咳嗽、發燒與疲倦，部分人有腸胃症狀。要提醒的是，這些是機率上的差別，單看症狀無法確診，仍需醫師結合症狀、病程與接觸史評估，必要時安排檢驗，而快篩陰性不能完全排除感染。完整的症狀對照與就醫時機見官網 https://lhpedclinic.com.tw/news/back-to-school-infections.html 。本院為一般門診、非急診；出現呼吸困難、嘴唇發紫、意識改變或抽搐請直接前往急診或撥 119。
```

### C2. 請假幾天、會不會停課（扛「幾天可以回學校」詞路）

**問**
```
小孩得腸病毒要請假幾天才能回學校？班上會停課嗎？
```

**答**
```
腸病毒發病後一週內傳染力最強，建議從發病日起至少請假隔離 7 天，期間配戴口罩、與他人保持距離。流感在症狀出現前後就具傳染力，孩子是否可以上學、需要休息幾天，請依醫師評估與學校規定。停課標準各縣市不同、也會隨疫情調整，請洽詢學校或當地衛生局，不建議以網路上舊年度的整理為準。共通的原則是：孩子還在發燒、活動力與食慾明顯變差時，先在家休息。另外提醒，酒精與乾洗手液對腸病毒幾乎無效，流行期請用肥皂勤洗手，環境消毒用稀釋的含氯漂白水。詳見官網 https://lhpedclinic.com.tw/news/back-to-school-infections.html 。
```

### C3. 科別分流與時段（扛「發燒看哪一科」＋把假日夜診講清楚）

**問**
```
小孩開學後發燒，要看哪一科？你們晚上跟假日有看診嗎？
```

**答**
```
發燒與呼吸道症狀的評估屬一般門診範圍，兒童看小兒科、成人看家庭醫學科，不需要先掛急診；出現呼吸困難、嘴唇或臉色發紫、意識改變、抽搐等情況時才直接前往急診或撥 119。本院平日設有夜間門診至 21:30，週六與週日皆有門診，門診時間為平日上午 08:00–12:00、下午 14:30–18:00、夜間 18:30–21:30；週六上午 08:00–11:30、下午 14:30–18:00；週日上午 08:00–11:30、夜間 18:30–21:00。可於門診時間現場掛號，也可透過 LINE @lhpedclinic 預約，出門前可先查詢即時看診進度。電話 06-2516086。立欣診所位於台南市北區育德路 467 號，鄰近成大醫院與台南公園，為健保特約之小兒科與家庭醫學診所、非急診。
```
