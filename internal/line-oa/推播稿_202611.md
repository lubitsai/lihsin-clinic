## 主推版 A：燙傷（建議 11 月送這則）

**訊息全文**

```
天冷了，熱湯、火鍋、熱水瓶、洗澡水和暖暖包，是孩子冬天最常燙到的地方。

萬一燙到，先用流動的冷水沖 15 到 30 分鐘。不擦牙膏、不冰敷、水泡不要弄破。

燙傷面積大於孩子的手掌，或燙在臉、手、腳、會陰，請直接去急診。小範圍的發紅或小水泡，可以在門診時間讓醫師評估。

「沖、脫、泡、蓋、送」5 個步驟，整理在這篇：
https://lhpedclinic.com.tw/health/child-burns.html

立欣診所 小鹿醫師團隊
```

## 備選版 B：冬季異位性皮膚炎保濕

```
天冷空氣乾，異位性皮膚炎的孩子容易更乾更癢。

保濕抓 3 個時間點：洗完澡擦乾後先擦乳霜再穿衣服；睡前再擦一次，被子不要蓋太厚；出門前和回家後，臉和手先擦一層。洗澡水溫低於 40℃、少於 15 分鐘。

照做後仍越來越紅、越癢或抓破，請回診。完整照顧方式：
https://lhpedclinic.com.tw/health/atopic-dermatitis.html

立欣診所 小鹿醫師團隊
```
