## 需要修正的 5 處

### ① 第 2 題「週六、週日有看診嗎？」——禁語「少數」

現在：「有！立欣診所週六、週日都有門診，**是台南北區少數假日有診的小兒科**。…」
問題：「少數」在行銷工具組禁語清單（合規紅線第 1 條），屬自稱式比較。

修正稿：
```
有，週六、週日都有門診。
週六：上午 08:00–11:30、下午 14:30–18:00
週日：上午 08:00–11:30、夜間 18:30–21:00
各時段看診醫師與臨時異動，以官網最新公告為準。電話 06-2516086。
```

### ② 第 6 題「孩子發燒幾度需要看醫生？」——與官網衛教內容不一致（醫療內容）

現在：「3 個月以下嬰兒超過 38°C → 立即就醫；3 個月～3 歲超過 39°C，或發燒超過 24 小時 → 建議就診；3 歲以上發燒超過 3 天…」
問題：官網〈小孩發燒幾度要看醫生？〉（蔡宗儒醫師撰寫）沒有「39°C」「24 小時」這兩個門檻，並強調判斷重點是活力與精神、不是體溫數字；3 個月以下是「不論幾度都建議立即就醫」。兩邊說法不同，家長會無所適從。

修正稿（逐句取自官網 `health/child-fever.html`）：
```
依台灣兒科醫學會建議，中心體溫達 38℃ 以上算發燒。
・3 個月以下嬰兒：發燒不論幾度，都建議立即就醫
・發燒持續超過 3 天未改善，或退燒後精神活力仍明顯變差：請就醫
・嘴唇或臉色發紫、脖子僵硬、皮膚出現不會褪色的出血點或紫斑：直接前往急診或撥 119
判斷重點是孩子的活力、食慾與精神，不只看體溫數字。本診所非急診。
完整說明：https://lhpedclinic.com.tw/health/child-fever.html
```

### ③ 第 9 題「有提供自費疫苗嗎？要預約嗎？」——疫苗四項但書缺兩項、「現貨供應」為絕對宣稱

現在：「立欣診所自費疫苗**現貨供應**，包含…」，只有「先來電確認現貨」「最後一診前 1 小時停止施打」兩項。
問題：缺「依原廠仿單」「接種前由醫師評估」（合規紅線第 3 條四項但書缺一不可）；官網寫的是「現貨品項會變動」。

修正稿（依官網 `services/vaccination.html`）：
```
有，自費疫苗包含 RSV 單株抗體（樂唯初）、HPV（嘉喜9價）、帶狀皰疹（欣剋疹）、15價肺炎鏈球菌、腸病毒71型等。
適用對象與劑數依原廠仿單，接種前由醫師評估。現貨品項會變動，請先來電 06-2516086 或在 LINE 詢問。
每日最後一診結束前 1 小時停止施打疫苗。
```

### ④ 第 4 題「要怎麼預約？需要現場排隊嗎？」——與官網預約規則不一致

現在：「可以電話 06-2516086 或 LINE @lhpedclinic 預約掛號，也可現場掛號。我們有『免排雲端』看診進度系統…」
問題：官網就診指南寫明「電話預約是由櫃檯人員代您在同一套系統操作，不另外保留名額」，且現場掛號有固定開始時間；「免排雲端」不是官網用的名稱。

修正稿（依官網 `visit-guide.html`）：
```
可以用 LINE 選單「線上掛號」網路預約，或在門診時間來電 06-2516086，由櫃檯代您在同一套系統預約（不另外保留名額）。
也可以現場掛號：早診 08:00、午診 14:30、晚診 18:00 開始。
到診前可用 LINE 選單「看診進度」查目前號碼，快到號再出門。
```

### ⑤ 基本資訊「Average $101 ~ $300」——公開價格

問題：主頁基本資訊顯示消費區間價格。`00` §4-12「價格數字原則一律不寫」（公開管道），醫療法第 61 條。
建議：OA Manager → 主頁 → 基本資訊 → 預算／價格區間，**改為不顯示**（若該欄為必填，請截圖給 session 再評估）。
