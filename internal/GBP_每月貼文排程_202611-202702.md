## 一、固定規則（沿用歷批，不新增）

- 每月 **2 則**：1 則「季節衛教」＋1 則「就醫資訊」。貼文 6 個月自動封存，時效內容只走貼文、不寫進企業簡介（08-31 判定）。
- 按鈕一律「瞭解詳情」，連到對應官網頁。**貼文內文不加 UTM**（09-24 決定；只有企業簡介的網站欄位帶 `utm_campaign=gbp`，09-26x）。
- 合規照 `00` §4：零價格數字、無自稱超級詞、疫苗題四但書齊備、明示非急診。
- 圖片用官網已核可的資訊圖；不得出現可辨識的病患臉孔。
- 發完在本檔第三節打勾，月報 `03` §三 C 段記「網站點擊」。

## 三、可直接貼的稿（本批 2 則；其餘月份到時依同版型起稿）

### B1｜假日出門前準備（就醫資訊；2026-11）

**按鈕**：瞭解詳情 → `https://lhpedclinic.com.tw/services/weekend-pediatrics.html`
**建議圖片**：`/images/weekend-pediatrics-20261024-infographic.jpg`

```
【週末帶孩子看診，出門前先準備這幾樣】

立欣診所週六、週日都有門診。假日來看診，帶齊這些東西會順一點：

・孩子的健保卡。當天要打疫苗的話，加帶兒童健康手冊（黃卡）。
・有發燒的話，記下量體溫的時間、部位與度數，以及退燒藥吃了哪一種、幾點吃、吃多少。
・正在吃的藥或藥袋，包含其他院所開的。
・出門前先用手機查看診進度，快到號再出發。

3 個月以下嬰兒發燒、呼吸困難、抽搐或叫不醒，請直接前往急診。本院為一般門診、非急診。

各時段看診醫師與掛號方式，請見官網假日門診頁。
電話 06-2516086｜LINE @lhpedclinic
```

### B2｜看皮膚前三件事（就醫資訊；2026-12）

**按鈕**：瞭解詳情 → `https://lhpedclinic.com.tw/services/skin-conditions.html`
**建議圖片**：無專屬資訊圖（該頁列在 `00` §6 缺圖清單）；可不附圖，或用診所外觀照。

```
【孩子起疹子，到診間卻退了？看診前先做三件事】

疹子常常一陣一陣的，到了診間不一定還看得到。出門前準備好這三樣，醫師比較好判斷：

・拍下發作時的樣子：用手機拍清楚，記下出現的時間與部位。蕁麻疹單一處通常在 24 小時內消退，照片可以補上這一段。
・帶著正在用的藥：最近擦過的藥膏、吃過的藥，包含其他院所開的和自己買的，連同藥袋或外盒一起帶來。
・回想最近 1～2 天的變化：新吃的食物、新用的藥、換過的沐浴乳或洗衣精、新衣物，以及最近有沒有感冒。

皮疹合併嘴唇腫脹、呼吸困難或頭暈，可能是嚴重過敏反應，請撥打 119。

立欣診所為小兒科與家庭醫學診所，非皮膚專科；需要專科處置時協助轉介。
電話 06-2516086｜LINE @lhpedclinic
```

內容逐句取自本批 PR 的頁面新增段落，**未新增任何醫療事實**；急診句取自兩頁既有的危險徵象區。
